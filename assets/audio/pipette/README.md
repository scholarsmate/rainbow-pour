# Pipette Assets

Selected from "40 CC0 water / splash / slime SFX" by rubberduck on OpenGameArt.

Source: https://opengameart.org/content/40-cc0-water-splash-slime-sfx
License: CC0

The files in this folder are renamed working copies of the original `slime_*.ogg`,
`bubble_*.ogg`, and `splash_*.ogg` sounds for suck, squirt, and stir pipette
effects. No attribution is required.
