# Rainbow Hanoi

A colorful 2D puzzle game inspired by the classic Towers of Hanoi.

## About

This is a Godot 4.x project that reimagines the classic Towers of Hanoi puzzle with vibrant colors and smooth 2D gameplay.

## Getting Started

1. Install Godot 4.x from https://godotengine.org/
2. Open the project in Godot
3. Run the main scene

## How to Play

The classic Towers of Hanoi rules apply:
- Move disks from one tower to another
- Only one disk can be moved at a time
- A larger disk cannot be placed on top of a smaller disk

## Project Structure

- `scenes/` - Game scenes
- `scripts/` - GDScript files
- `assets/` - Game assets (sprites, sounds, etc.)
